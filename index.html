Алексей, у проекта есть две точки входа и одна общая цель. Можно начать с команды агентов или с монтажа в Telegram и постепенно связать производство, публикацию и аналитику.

Три варианта развития

01 / Команда в Telegram

Один бот, два специалиста

В Telegram у вас один чат с ботом Hermes. Внутри работают Маша и Паша. Маша на GPT придумывает начало и пишет сценарий. Паша на Claude выбирает фрагменты, добавляет субтитры и запускает сборку видео.

Вы отправляете видео с телефона и пишете «Маша, предложи три варианта начала». Когда вы выберете вариант, бот сам передаст сценарий и исходник Паше. Готовый ролик придёт в тот же чат. Если нужна правка, напишите «Паша, сократи вступление».

Можно поручить весь процесс одним сообщением «Сделай ролик целиком». Бот сам распределит работу. Всё выполняется на сервере, поэтому ваш компьютер может быть выключен.

02 / Автономный монтаж

Отправили видео. Получили ролик

Вы отправляете исходник с телефона. Один Claude ведёт весь монтаж по вашим правилам: выбирает начало, решает, что сократить, и передаёт план на сборку. Сервер возвращает готовый MP4 в Telegram при выключенном домашнем компьютере.

Как настраиваем под вас. Даём Claude удачные примеры, правила склеек, шаблоны титров и финалов. Расшифровку и экспорт выполняют отдельные инструменты. По вашей правке бот пересобирает видео.

Первый тест — вертикальный ролик на 30–40 секунд по вашему референсу.

03 / Полная система

Автопилот с ручным управлением

По умолчанию бот сам доводит запись до готового видео. Если выпуск требует внимания, вы обращаетесь к нужному специалисту в той же карточке. Можно поменять хук или монтаж и сохранить предыдущую версию.

От записи до результатов. Из одного материала система готовит выпуск YouTube и короткие версии с разными хуками и финалами. Согласованные ролики идут в календарь. Бот возвращает статусы публикаций и доступные метрики, чтобы вы могли выбрать, какие форматы повторить.

Добавляем библиотеку оформления, пакетную сборку и пробные Reels после отдельных проверок.

Что проверили до старта

  • Агенты и подписки. Hermes поддерживает параллельные задачи и отдельные профили. Для видимых участников группы каждому профилю нужен свой Telegram-бот. Общую карточку и передачу файлов между ролями настраиваем отдельно. Для GPT есть вход через ChatGPT/Codex. Claude Pro и Max можно подключить через экспериментальный плагин DirectSDK. Он использует вход в Claude Code на сервере и работает без отдельного API-ключа. Для пилота проверим авторизацию, расход лимита и сборку одного ролика на вашей подписке. Отдельный API остаётся запасным вариантом. Claude DirectSDK Группы Telegram · Делегирование · Подключение моделей
  • Видео и сервер. Локально проверили нарезку и экспорт тестового MP4. Для реального ролика проверим точность титров и склеек. Стандартный Telegram Bot API позволяет боту скачать до 20 МБ. Для тяжёлых исходников предусмотрим загрузку по защищённой ссылке или отдельный сервер Telegram Bot API. FFmpeg · Telegram Bot API
  • Публикация и цифры. Metricool поддерживает планирование обычных и пробных Reels, а также статистику Reels. Автоматизацию из бота проверим на доступном тарифе и нужном методе интеграции. Для пробных роликов доступ решает Instagram при публикации, а точный лимит не раскрывается. Частота 3–5 в день остаётся гипотезой. Для YouTube загрузку и режим видимости проверим на канале отдельным тестом. Пробные Reels · Metricool API · Метрики · YouTube API
