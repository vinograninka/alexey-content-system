Ваша система
для выпуска контента

Алексей, начнём с монтажа в Telegram. Затем добавим сценариста и научим команду подхватывать задачи друг друга. Когда выпуск роликов будет отлажен, подключим публикацию и статистику.

Три этапа развития

01 / Монтаж в Telegram

Отправили видео. Получили ролик

Вы отправляете исходник с телефона в бот Hermes. Claude работает монтажёром: по вашим примерам выбирает начало, убирает лишнее и задаёт оформление. Инструменты на сервере расшифровывают речь и собирают видео с субтитрами.

На выходе — готовый MP4 в том же чате. Если нужна правка, напишите «Сократи вступление». Домашний компьютер может быть выключен.

Начинаем с одного вертикального ролика на 30–40 секунд по вашему референсу.

02 / Команда в одном боте

Маша и Паша работают вместе

Маша на GPT придумывает хук и пишет сценарий. Паша на Claude монтирует. Вы можете обратиться к любому из них или написать «Сделай ролик целиком». Бот сам передаёт сценарий, исходник и правки.

Если у модели закончился лимит. Настраиваем резерв в обе стороны. Например, GPT может продолжить работу Паши по тем же правилам, с тем же исходником и сохранёнными результатами. Для вас Паша остаётся монтажёром.

Подмену проверяем на ваших подключениях и на задаче в середине монтажа.

03 / Полный цикл выпуска

От записи до статистики

Из одной записи система готовит несколько версий ролика. Вы утверждаете те, которые готовы к выпуску. Бот ставит их в календарь и через Metricool отправляет в Instagram по расписанию.

На выходе — статусы публикаций и доступные метрики в Telegram. Можно сравнить охват и просмотры версий и выбрать, какие форматы повторить.

Сначала проверяем публикацию одного согласованного Reel и получение его метрик. Пробный режим и регулярный выпуск проверяем отдельно.

Что проверили до старта

  • Агенты и подписки. Hermes поддерживает распределение задач между моделями и резервное переключение при распознанных ошибках. Правила ролей, файлы и состояние работы сохраняем в общей карточке. Автоматическую подмену при исчерпании лимита Claude через DirectSDK проверяем отдельно. Для GPT есть вход через ChatGPT/Codex. Claude Pro и Max можно подключить через экспериментальный плагин DirectSDK. Он использует вход в Claude Code на сервере и работает без отдельного API-ключа. Для пилота проверим авторизацию, расход лимита и сборку одного ролика на вашей подписке. Отдельный API остаётся запасным вариантом. Claude DirectSDK · Резервные модели · Делегирование · Подключение моделей
  • Видео и сервер. Локально проверили нарезку и экспорт тестового MP4. Для реального ролика проверим точность титров и склеек. Стандартный Telegram Bot API позволяет боту скачать до 20 МБ. Для тяжёлых исходников предусмотрим загрузку по защищённой ссылке или отдельный сервер Telegram Bot API. FFmpeg · Telegram Bot API
  • Публикация и цифры. Metricool поддерживает планирование обычных и пробных Reels, а также статистику Reels. Автоматизацию из бота проверим на доступном тарифе и нужном методе интеграции. Для пробных роликов доступ решает Instagram при публикации, а точный лимит не раскрывается. Частота 3–5 в день остаётся гипотезой. Для YouTube загрузку и режим видимости проверим на канале отдельным тестом. Пробные Reels · Metricool API · Метрики · YouTube API

Один ролик от исходника до выдачи

Пришлите один исходник и пример монтажа, который вам нравится. Проверим, что Claude доводит видео до готового файла в Telegram, и внесём одну правку. После этого добавим Машу и проверим, как специалисты передают и подхватывают задачи.
